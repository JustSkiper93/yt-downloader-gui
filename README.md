# YT Downloader

Простая программа с окном (GUI) для скачивания видео и звука с YouTube. Построена на Python, tkinter и [yt-dlp](https://github.com/yt-dlp/yt-dlp).

## Возможности

- Скачивание видео в mp4 или только звука в mp3
- Выбор качества видео (лучшее, 1080p, 720p, 480p, 360p)
- Скачивание целых плейлистов
- Выбор папки для сохранения
- Полоса прогресса со скоростью и оставшимся временем

## Установка

1. Установи [Python 3](https://www.python.org/downloads/)
2. Установи [ffmpeg](https://ffmpeg.org/download.html) (нужен для склейки видео со звуком и для mp3). В Windows: `winget install ffmpeg`
3. Установи зависимости:
   ```
   pip install -r requirements.txt
   ```

## Запуск

```
python yt_downloader_gui.py
```

Если скачивание вдруг перестало работать, обнови yt-dlp:

```
pip install -U yt-dlp
```

## Важно

Программа предназначена для личного использования: скачивай свои видео, контент с открытой лицензией или то, на что у тебя есть разрешение. Условия использования YouTube запрещают скачивание без разрешения правообладателя. Ответственность за использование лежит на пользователе.
